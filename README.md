# Harsh Singh – Portfolio

React + Vite portfolio. All content lives in `src/data.js`.

## Run locally
npm install
npm run dev        # opens http://localhost:5173

## Update content
Edit `src/data.js`, commit and push. Vercel / GitHub Pages redeploys automatically.

## Deploy (free, always online)
Vercel: Import this GitHub repo at vercel.com/new → Deploy (Vite is auto-detected).
GitHub Pages: Settings → Pages → Source: GitHub Actions. The workflow in .github/workflows deploys on every push.
